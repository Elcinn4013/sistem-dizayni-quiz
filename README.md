# Sistem Dizaynı — İmtahan Test Sistemi (240 Sual)

PDF-də olan bütün 240 sual əsasında hazırlanmış interaktiv və müasir quiz veb tətbiqi.

## 🌟 Əsas Xüsusiyyətlər

1. **Cavabların Hər Dəfə Təsadüfi Qarışdırılması (Shuffle):**
   - Orijinal PDF faylında bütün düzgün cavablar **A** bəndində idi.
   - Bu test sistemində hər dəfə test açıldıqda variantların (A, B, C, D, E) yeri tamamilə təsadüfi qaydada dəyişir.
2. **Aralıq Seçimi (Custom Range):**
   - İstədiyiniz sual nömrələrinin intervalını seçə bilərsiniz (Məs: 1-50, 51-100, 101-150, 151-200, 201-240 və ya fərdi olaraq 30-120).
3. **Təsadüfi 50 Sual Seçimi:**
   - Seçilmiş aralıqdan hər dəfə 50 sual (və ya istədiyiniz sayda) təsadüfi qaydada seçilir.
4. **2 Müxtəlif Rejim:**
   - **Təlim Rejimi (Məşq):** Variantı seçən kimi dərhal doğru/səhv olduğunu və düzgün cavabı göstərir.
   - **İmtahan Rejimi:** Real sınaq formatı, taymer və yekunda ətraflı nəticə hesabatı.
5. **Suallar Xəritəsi və Qısayollar:**
   - 1-dən 50-yə qədər sualların vəziyyətini göstərən naviqator (Xəritə).
   - Klaviatura qısayolları: `1-5` və ya `A-E` (variant seçimi), `→` / `←` (növbəti/əvvəlki), `F` (sualı işarələmək).
6. **Ətraflı Nəticə və Səhvlərin Təhlili:**
   - Test bitdikdə toplanan bal, faiz, düzgün/səhv/boş sayı göstərilir.
   - "Yalnız Səhvlər" filtri ilə səhv etdiyiniz sualları analiz edə bilərsiniz.
7. **Sual Bankı və Axtarış (240 Sual):**
   - Bütün 240 sual və düzgün cavabları içərisində açar sözlərlə axtarış imkanı.

## 🚀 Necə İşə Salmaq Olar?

### Üsul 1 (Sadə və Birbaşa):
- Sadəcə qovluqdakı `index.html` faylını iki dəfə klikləyərək istənilən brauzerdə (Chrome, Edge, Opera, Firefox və s.) açın. İnternet tələb olunmur!

### Üsul 2 (Lokal Server ilə):
- İstəsəniz brauzerinizdə `http://localhost:3000` ünvanına daxil ola bilərsiniz (Lokal server hazırda aktivdir).
